# DU Financial Accounting Tutor

A mobile-first learning and exam-practice website for **DU B.Com (Hons), Semester 1 – Financial Accounting**.

## Project 1 — MVP

The first working version includes:

- Study Mode with six starter topics
- English and Hinglish lesson toggle
- Exam-style MCQ, short-answer and long-answer practice
- Easy, medium, hard and mixed filters
- Browser-based progress saving
- Responsive light/dark interface
- No paid API or backend required

## Open the project

Download the repository and open `index.html` in a modern browser.

## Publish using GitHub Pages

Open **Settings → Pages → Deploy from a branch**, select **main** and **/(root)**, then save.
